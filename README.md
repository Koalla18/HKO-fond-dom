# Единое окно заявок · фонд «ДОМ»

Платформа, в которую стекаются все обращения в [фонд помощи животным «ДОМ»](https://fundhome.ru):
сообщения из ВКонтакте, Telegram, MAX, Одноклассников, почты, форм и чата на сайте, а также звонки,
которые сотрудник заносит вручную. У каждого обращения видно, **откуда оно пришло**, кто пишет и кто из
команды уже отвечает. Ответ из платформы уходит человеку туда же, откуда пришёл вопрос.

Из переписки рождаются **заявки** — оформленные просьбы и предложения по видам помощи фонда
(нашли животное, взять питомца, опека, передержка, волонтёрство, корма и вещи, стерилизация).
Они живут на отдельной доске от анкеты до итога.

ИИ-ассистент разбирает обращения и сам оформляет заявки (см. [docs/AI-AGENT.md](docs/AI-AGENT.md)) —
нужно только выбрать модель и вставить ключ API фонда в Настройках.

## Что умеет

- **Входящие в три колонки**: список с фильтрами (активные, мои, без ответственного, ведёт ИИ,
  решённые, спам) и поиском → переписка → карточка заявки и человека.
- **Один человек — одна история.** Если человек написал в ВК и на почту и оставил один адрес или
  телефон, его обращения собираются в одну карточку.
- **Статусы и разбор**: новая → в работе → ждём ответа → решена; срочность, категория по
  направлениям фонда (найдено животное, ветпомощь, передержка, опека, корма, стерилизация…),
  ответственный.
- **Заметки для коллег** — видны только сотрудникам.
- **Переписка как в мессенджере**: ответ на конкретное сообщение (в Telegram, ВК, MAX и WhatsApp —
  родным ответом, в почте и остальных — цитатой), смайлики, файлы скрепкой, вставкой или
  перетаскиванием, Enter — отправить, Shift+Enter — новая строка, копирование текста.
  В чате на сайте посетитель видит цитату и файлы фонда.
- **Живое обновление**: новые сообщения появляются без перезагрузки.
- **Повторы и дубли**: повторная доставка сообщения площадкой не создаёт дубль; решённая заявка
  открывается снова, если человек написал в течение 72 часов (или ответил на конкретное письмо).
- **Заявки**: доска по этапам с перетаскиванием (новая → рассмотрение → в работе → итог / отказ),
  список, карточка с анкетой, ответственным, историей и заметками, выгрузка в Excel. Этапы названы
  по смыслу вида: у «Взять питомца» итог — «Нашёл дом», у «Нашли животное» — «Помогли».
- **ИИ-ассистент** разбирает каждое обращение из всех каналов и сам оформляет заявку с ответами
  анкеты; по желанию отвечает людям. Работает с YandexGPT, GigaChat (cloud.ru), DeepSeek или любой
  моделью с OpenAI-совместимым API; ключ хранится зашифрованным.
- **Единый вид «жидкое стекло»** во всех разделах: фото дома на фоне (выбирается), полупрозрачные
  панели с размытием.
- **Обзор** в стиле «стекло» на фото дома: обращения, заявки, «Нашли дом» и ответ за час с
  мини-графиками и сравнением с прошлым периодом (неделя, месяц, год), «Требует внимания»,
  события, команда, цели месяца, каналы и заявки по видам. Фон выбирается.
- **Команда**: администратор и сотрудники, вход по почте и паролю.
- **Тестовая заявка** из любого канала — показать фонду, как всё выглядит, без настоящих ключей.

## Каналы

| Канал | Как приходят сообщения | Нужен HTTPS-домен |
|---|---|---|
| Почта | IMAP раз в минуту, ответ по SMTP | нет |
| ВКонтакте | Long Poll | нет |
| Telegram | опрос (или вебхук с доменом) | нет |
| MAX | опрос | нет |
| Чат на сайте | виджет одной строкой кода | нет |
| Формы сайта | адрес приёма; понимает поля форм fundhome.ru | нет |
| Телефон и приём | сотрудник заводит заявку вручную | нет |
| Одноклассники | вебхук | **да** |
| WhatsApp, Instagram, Facebook | вебхук Meta | **да** |

Пошагово для каждой площадки — [docs/CHANNELS.md](docs/CHANNELS.md).

## Запуск у себя

Нужны Node.js 22+ и PostgreSQL 14+.

```bash
npm install
cp .env.example .env.local   # заполнить DATABASE_URL, APP_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm run dev                  # http://localhost:3050
```

При первом старте платформа сама создаёт таблицы и администратора из `ADMIN_EMAIL`/`ADMIN_PASSWORD`.
Демо-наполнение локальной базы (каналы и обращения на тему фонда):

```bash
node --env-file=.env.local scripts/demo.mjs
# год истории обращений и заявок, чтобы ожили графики обзора (стирает обращения и заявки!)
node --env-file=.env.local scripts/demo-history.mjs --reset
node --env-file=.env.local scripts/demo.mjs
```

Песочница чата на сайте: `http://localhost:3050/widget-demo?channel=<id канала «Чат на сайте»>`.

## Деплой

Один контейнер с приложением + PostgreSQL — см. [docs/DEPLOY.md](docs/DEPLOY.md).

```bash
cp .env.example .env   # APP_SECRET, ADMIN_*, POSTGRES_PASSWORD, APP_URL=http://<IP>:3050
docker compose up -d
```

**Маленький сервер (2 ГБ, рядом другие сайты)** — сборка на своём компьютере, на сервер уходит готовая:

```bash
scripts/deploy.sh                                # по умолчанию jakone@31.130.155.216 → ~/dom-inbox
DEPLOY_HOST=user@1.2.3.4 scripts/deploy.sh       # другой сервер
```

Первый запуск сам создаёт на сервере `.env` со случайными ключами и паролем администратора
(посмотреть: `ssh <сервер> grep ADMIN_PASSWORD dom-inbox/.env`). Лимиты памяти — 512 МБ приложению,
256 МБ базе (`deploy/docker-compose.server.yml`). Повторный запуск обновляет приложение, база и файлы сохраняются.

## Устройство

- `src/lib/channels/` — всё про каналы: каталог (`catalog.ts`), приём сообщений и склейка заявок
  (`ingest.ts`), отправка ответов (`outbound.ts`), менеджер опроса (`manager.ts`), адаптеры площадок
  (`adapters/*`). Новый канал = новый адаптер с методами `run` / `send` / `test` / `webhook`.
- `src/lib/agent/` — шов под ИИ-агента: каждое новое сообщение передаётся провайдеру, который может
  ответить, разобрать заявку, оставить заметку или передать её человеку.
- `src/db/schema.ts` — таблицы: сотрудники, каналы, люди и их способы связи, заявки, сообщения.
  Ключи и пароли каналов хранятся зашифрованными (AES-256-GCM, ключ `APP_SECRET`).
- `src/app/(app)/` — экраны кабинета, `src/app/api/` — API, `src/app/widget.js` — виджет для сайта.

Интерфейс построен на открытых компонентах [shadcn/ui](https://ui.shadcn.com) (MIT), значки площадок —
[Simple Icons](https://simpleicons.org) (CC0).
