# Подключение каналов

Все каналы подключаются в кабинете: **Каналы → Подключить**. В карточке канала — те же шаги,
поля для ключей, кнопка «Проверить подключение» и «Тестовая заявка».

Ключи и пароли хранятся в базе зашифрованными; в интерфейсе после сохранения видна только маска
`••••1234`. Пустое поле при редактировании ключ не стирает.

## Что нужно от фонда

| Канал | Что прислать / сделать |
|---|---|
| Почта | адрес ящика, IMAP/SMTP-серверы, **пароль приложения** (не основной пароль) |
| ВКонтакте ([vk.com/fundhome_ru](https://vk.com/fundhome_ru)) | ID сообщества и ключ доступа (права «Сообщения» и «Управление») |
| Telegram | токен бота от @BotFather (бот — отдельный от канала t.me/fundhome_ru) |
| MAX | токен бота с платформы MAX для партнёров |
| Одноклассники ([ok.ru/fundhome](https://ok.ru/fundhome)) | ключ доступа группы; нужен HTTPS-домен платформы |
| Формы сайта | доступ к коду сайта, чтобы формы дополнительно отправлялись в платформу |
| Чат на сайте | вставить одну строку кода перед `</body>` |
| WhatsApp / Instagram | приложение Meta + проверка Meta; нужен HTTPS-домен (см. оговорку ниже) |

## Почта

1. В ящике включите доступ по IMAP.
2. Создайте **пароль приложения**: Яндекс ID → Безопасность → Пароли приложений
   (Mail.ru и Gmail — аналогично).
3. Типовые серверы: Яндекс — `imap.yandex.ru:993` / `smtp.yandex.ru:465`;
   Mail.ru — `imap.mail.ru:993` / `smtp.mail.ru:465`; Gmail — `imap.gmail.com:993` / `smtp.gmail.com:465`.
4. Платформа принимает письма **с момента подключения** (старый архив не тянет), проверяет ящик
   раз в минуту. Цитаты предыдущих писем отрезаются, ответ на письмо фонда попадает в ту же заявку.
   Автоответы, рассылки и письма самого фонда не превращаются в заявки.

## ВКонтакте

1. Сообщество → Управление → **Сообщения**: включить сообщения сообщества.
2. Управление → Работа с API → **Ключи доступа**: создать ключ с правами «Сообщения сообщества»
   и «Управление сообществом».
3. Работа с API → **Long Poll API**: включить, версия 5.199, в типах событий отметить
   «Входящее сообщение».
4. В платформе указать ID сообщества (виден в «Работа с API») и ключ.

Принимаются личные сообщения сообществу; беседы с несколькими участниками пропускаются.
Кнопка «Начать» получает приветствие из настроек канала.

## Telegram

1. В Telegram: **@BotFather → /newbot** → имя и адрес бота (например, `@fundhome_help_bot`).
2. Токен вставить в платформу. Режим «Опрос» работает без домена.
3. Ссылку на бота добавить в описание канала t.me/fundhome_ru и на сайт.

> **Сервер в России.** `api.telegram.org` из российских дата-центров часто недоступен по IPv4.
> Если «Проверить подключение» не проходит, укажите в `.env` адрес прокси Bot API:
> `TELEGRAM_API_BASE=https://<ваш-прокси>` — код ходит туда вместо api.telegram.org.

## MAX

1. Зарегистрировать организацию на платформе MAX для партнёров и создать бота.
2. Токен вставить в платформу. Сообщения забираются опросом (`GET /updates`), ответ уходит в тот же
   диалог. При переходе на HTTPS-домен MAX рекомендует вебхуки — адрес вебхука канала уже есть:
   `https://<домен>/api/webhooks/<id канала>`.

## Одноклассники

1. Группа на ok.ru (полная версия сайта) → Настройки → **Сообщения** → «Получить ключ доступа».
2. Ключ вставить в платформу и включить канал — платформа сама оформит подписку на сообщения
   (`POST /graph/me/subscribe`). Одноклассники присылают события **только на HTTPS-адрес**, поэтому
   канал заработает после подключения домена. Адрес вебхука защищён секретным ключом канала.
3. Формат событий ОК задокументирован не полностью — первое сообщение после подключения стоит
   проверить вживую.

## Формы на сайте

Адрес приёма: `POST https://<платформа>/api/public/form/<id канала>` — принимает JSON, обычную форму
и multipart. **Поля форм fundhome.ru понимаются как есть**:

| Поле на сайте | В заявке |
|---|---|
| `form[name]`, `form[phone]`, `form[email]` | имя, телефон, почта человека |
| `form[theme]` | тема заявки |
| `form[text]` | текст обращения |
| `form[animal]` | ссылка на анкету животного → категория «Опека» |
| `form[type]` | «Вид помощи»; «Возьму на передержку» → категория «Передержка» |
| `category` | категория явно (одна из списка) |
| `website` | ловушка для ботов — люди её не видят |
| `redirect` | куда вернуть человека после отправки |

Ответ на заявку с формы уходит **письмом** через ящик, выбранный в настройках канала. Если человек
оставил только телефон — платформа подскажет перезвонить.

## Чат на сайте

Строка кода из карточки канала вставляется перед `</body>` на всех страницах:

```html
<script src="https://<платформа>/widget.js" data-channel="<id канала>" async></script>
```

Кнопка чата в углу страницы; посетитель пишет без регистрации, ответ фонда появляется у него в окне
чата. Можно оставить почту, чтобы ответ не потерялся, если человек закроет страницу.

## WhatsApp, Instagram, Facebook

Подключаются через приложение на developers.facebook.com, нужен HTTPS-домен и проверка приложения
Meta. В карточке канала — адрес вебхука и токен проверки для кабинета Meta.

> Компания Meta признана в России экстремистской организацией, Instagram и Facebook заблокированы.
> Решение о приёме обращений через эти площадки — за фондом; на старте рекомендуем ВК, Telegram,
> MAX, Одноклассники, почту и сайт — там аудитория фонда уже есть.

## Чего нет и почему

- **Дзен и RuTube** — у площадок нет API личных сообщений, только комментарии.
- **Отправка файлов** в MAX, Одноклассники, WhatsApp и Instagram — пока только текстом; файлы
  от людей из этих каналов принимаются.
