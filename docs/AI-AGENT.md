# ИИ-ассистент: как подключить

Ассистент работает внутри платформы: получает каждое входящее сообщение из всех каналов, разбирает
его и сам оформляет заявку на доске «Заявки». Нужно только выбрать модель и вставить ключ API фонда.

## Подключение — 3 шага

1. **Настройки → ИИ-ассистент → Модель**: YandexGPT, GigaChat (cloud.ru), DeepSeek, OpenAI или
   «Другой сервис» (любой адрес с OpenAI-совместимым API: Timeweb, OpenRouter, свой сервер).
2. Вставить **ключ API** (для YandexGPT ещё ID каталога Yandex Cloud), нажать «Сохранить».
   Ключ хранится зашифрованным (AES-GCM, `APP_SECRET`) и наружу не отдаётся — в кабинете видна только маска.
3. **Проверить на примере**: вставить текст обращения и нажать «Что сделает ассистент» — покажет
   тему, срочность, категорию и заявку с анкетой. Ничего не сохраняется и никому не отправляется.
   Затем включить «Ассистент работает».

## Что он делает

| Переключатель | Поведение |
|---|---|
| Оформляет заявки (по умолчанию вкл.) | из переписки определяет вид заявки и заполняет поля анкеты тем, что человек уже написал. Повторные сообщения дополняют ту же заявку. На доске — пометка «оформил ассистент» |
| Отвечает людям (по умолчанию выкл.) | коротко отвечает в канал человека и задаёт уточняющие вопросы (адрес, фото, состояние). Первый ответ подписан «Ассистент фонда «ДОМ»». После заданного числа ответов зовёт сотрудника |

Всегда: ставит тему, краткое изложение, категорию и срочность; передаёт сотруднику деньги,
документы, жалобы, СМИ, угрозу жизни и всё, в чём не уверен.

**Два режима.** Новое обращение ассистент ведёт сам. Как только сотрудник ответил человеку, ассистент
работает молча: дополняет разбор и заявку, но людям не пишет и не меняет то, что уже поставил сотрудник.
В карточке обращения есть «Разобрать ассистентом» — ручной запуск на любом обращении.

## Как устроено

- `src/lib/agent/llm.ts` — запрос к модели (`/chat/completions`, ответ одним JSON), системный промпт
  со всеми видами заявок и полями из `src/lib/applications/catalog.ts`, разбор ответа, перевод в действия.
- `src/lib/agent/presets.ts` — адреса и модели по умолчанию для каждого сервиса.
- `src/lib/agent/index.ts` — очередь на обращение (разборы одного обращения идут по одному, без дублей
  заявок) и выполнение действий: `classify`, `application`, `reply`, `handoff`, `note`.
- Ручки: `POST /api/settings/ai-test` (проверка на примере), `POST /api/requests/:id/agent` (ручной разбор).

## Персональные данные

Для моделей за рубежом (DeepSeek, OpenAI, «Другой сервис») телефоны и почты в тексте заменяются на
`[телефон]`/`[почта]` — для разбора они не нужны. YandexGPT и GigaChat получают текст как есть: данные
остаются в России.

## Выбор модели

| Модель | Плюсы | Учесть |
|---|---|---|
| YandexGPT, GigaChat | данные в России, оплата рублями | нужен аккаунт Yandex Cloud / cloud.ru |
| DeepSeek | дёшево, отвечает из России | данные уходят за рубеж (без телефонов и почт) |
| OpenAI | лучшее качество | из России API закрыт — нужен прокси или сервер за рубежом |

## Честность перед людьми

Ассистент представляется ассистентом и не выдаёт себя за сотрудника: для фонда это вопрос доверия,
а правила площадок требуют, чтобы человек понимал, что пишет боту.
